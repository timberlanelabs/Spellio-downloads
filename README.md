# Spellio downloads

[Install Spellio](https://timberlanelabs.github.io/Spellio-downloads/) from Safari on an iPhone or iPad registered for this Ad Hoc build.

Version 0.1.0, build 1. Requires iOS/iPadOS 18 or later. Provisioning profile expires August 20, 2027.

The download is public; installation is limited to devices included in the signed provisioning profile. Source code is maintained separately.
